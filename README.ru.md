MizEdit позволяет редактировать брифинги, словари локализации, изображения, аудио, радиосообщения, скрипты и отдельные структуры миссии без ручной распаковки ZIP и правки Lua.

> [!IMPORTANT]
> При сохранении только перевода MizEdit оставляет `mission` и `l10n/DEFAULT/*` побайтно неизменными. Lua-файлы новой локали сохраняются в UTF-8 без BOM — именно такой формат принимает DCS.

## Скачать

Готовый архив Windows x64 находится в разделе [GitHub Releases](https://github.com/Mewt0/dcs-miz-editor/releases/latest). Распакуйте его и запустите `MizEdit.exe`.

Требования: Windows 10/11 x64. Release автономный, отдельная установка .NET не требуется.

## Возможности программы

### Брифинг и локализация

![Редактор брифинга](docs/assets/screenshots/01-briefing.png)

Открывайте `.miz`, переключайте локали, редактируйте брифинг и значения `DictKey_*` из `l10n/<locale>/dictionary`.

### Изображения миссии

![Редактор изображений](docs/assets/screenshots/02-pictures.png)

Добавляйте, заменяйте и удаляйте изображения брифинга и триггеров с сохранением ссылок `ResKey_*`.

### Аудиоресурсы

![Редактор аудио](docs/assets/screenshots/03-audio.png)

Просматривайте и прослушивайте локализованное аудио, заменяйте файлы без изменения ключей, используемых логикой миссии.

### Триггеры и маршрутные задачи

![Просмотр триггеров и задач](docs/assets/screenshots/04-triggers.png)

MizEdit показывает обычные триггеры и вложенные действия `ComboTask`, `WrappedAction`, `TransmitMessage`, скрипты, частоты и действия по целям.

### Радиосообщения и субтитры

![Редактор радиосубтитров](docs/assets/screenshots/05-radio.png)

Редактируйте субтитры `TransmitMessage` с контекстом группы и задачи, длительностью, DictKey и привязанным аудиофайлом.

## Рабочее пространство перевода

- Компактный нумерованный экспорт без показа внутренних `DictKey_*` переводчику.
- Стабильная идентификация пакета и совместимость со старыми маркерами.
- Блочная Smart Paste-вставка с поддержкой многострочных ответов.
- Дедупликация одинаковых оригиналов.
- Обязательный предпросмотр вставки: изменено, пропущено, отклонено и отсутствует.
- Отслеживание пропущенных номеров — например, строки 500 в пакете на 1000 строк.
- Очередь AI-перевода через Gemini или Ollama-совместимый провайдер.
- Контрольные точки для продолжения прерванного перевода.

## Безопасность сохранения и проверка качества

Перед сохранением MizEdit показывает:

- изменённые ключи перевода;
- добавляемые, заменяемые и удаляемые файлы архива;
- проблемы с плейсхолдерами, переносами, частотами, координатами и длиной текста;
- непереведённый текст и разные переводы одинакового оригинала;
- подозрительные изменения Lua и технических строк.

При сохранении перевода создаётся полный `l10n/RU/dictionary` с подстановкой неизменённых значений из DEFAULT. Файл `mission` не пересобирается. Перед заменой существующей `.miz` создаётся резервная копия.

## Структура миссии DCS

Файл `.miz` является ZIP-архивом. Основные элементы:

- `mission` — главная Lua-таблица миссии;
- `options`, `warehouses`, `theatre` — параметры миссии;
- `l10n/<locale>/dictionary` — локализованный текст `DictKey_*`;
- `l10n/<locale>/mapResource` — привязка файлов к `ResKey_*`;
- `l10n/<locale>/*` — аудио, изображения, скрипты и другие ресурсы;
- `KNEEBOARD/IMAGES/*` — страницы наколенного планшета.

## Сборка из исходников

Понадобятся Windows и .NET SDK 10.

```powershell
dotnet restore .\mizedit.csproj
dotnet build .\mizedit.csproj -c Release
dotnet run --project .\mizedit.csproj
```

Запуск целевого теста безопасной локализации:

```powershell
dotnet run --project .\tests\GreenLine.Integration\GreenLine.Integration.csproj -c Release -- --briefing-locale-smoke
```
